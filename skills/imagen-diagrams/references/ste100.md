# STE100 principles

Write captions, explanations, glossary entries, navigation, and skill-authored prose using ASD-STE100 Simplified Technical English principles.

- Use short, direct sentences.
- Prefer one main idea per sentence.
- Use active voice where practical.
- Use the same term for the same concept.
- Do not replace technical terms with synonyms only to create variety.
- Prefer concrete verbs.
- Avoid idioms, slang, and unnecessary metaphors.
- Make cause and effect explicit.
- State conditions before actions when this improves clarity.

Do not use em dash characters. Rewrite the sentence. Do not replace em dashes mechanically with hyphens.

The writing must remain professional and readable. Use STE100 to improve clarity, not to remove intellectual depth.
